# Simply Smart Money

A beautiful, modern personal finance blog built with Next.js 15, React 19, and Tailwind CSS.

## 🎨 Features

- **Modern Design**: Pinterest-style layout with deep navy blue color palette
- **Responsive**: Mobile-first design that looks great on all devices
- **Fast Performance**: Built with Next.js 15 for optimal speed
- **SEO Optimized**: Structured data and meta tags for search engines
- **Blog System**: Easy-to-manage blog posts with categories
- **Contact Form**: Built-in contact form for user inquiries
- **Google Fonts**: Playfair Display (headings) and Source Sans Pro (body)

## 📋 Pages

- **Home**: Hero section with featured articles and newsletter signup
- **Blog**: All blog posts with category filtering
- **Individual Posts**: Full-width blog post pages with related articles
- **About**: Information about Simply Smart Money
- **Contact**: Contact form for inquiries
- **Privacy Policy**: Privacy policy page

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/simply-smart-money.git
cd simply-smart-money
```

2. Install dependencies:
```bash
npm install
```

3. Create environment variables:
```bash
cp .env.example .env.local
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser
